Conceptos básicos
  • Álgebra: uso de letras y números para representar cantidades.
  • Binomio: expresión algebraica con dos términos.
  • Producto notable: multiplicación que sigue una regla conocida.
  • Términos semejantes: términos con las mismas variables y exponentes.
  • Factorización: convertir una expresión algebraica en una multiplicación de factores.

Productos notables

1. Binomio al cuadrado

Regla: se eleva al cuadrado el primer término, se suma el doble producto de ambos términos y se agrega el cuadrado del segundo.

Ejemplo: (2x + 3)²

Paso 1: (2x)² = 4x²

Paso 2: 2(2x)(3) = 12x

Paso 3: 3² = 9

Resultado: (2x + 3)² = 4x² + 12x + 9

2. Binomio al cubo

Regla: se calcula el cubo del primer término, tres veces el cuadrado del primero por el segundo, tres veces el primero por el cuadrado del segundo y el cubo del segundo.

Ejemplo: (x + 3)³

Paso 1: x³

Paso 2: 3(x²)(3) = 9x²

Paso 3: 3(x)(3²) = 27x

Paso 4: 3³ = 27

Resultado: (x + 3)³ = x³ + 9x² + 27x + 27

3. Binomios con término común

Regla: se eleva al cuadrado el término común, se suma la suma de las constantes multiplicada por el término común y se agrega el producto de las constantes.

Ejemplo: (y + 2)(y + 6)

Paso 1: y · y = y²

Paso 2: (2 + 6)y = 8y

Paso 3: 2 · 6 = 12

Resultado: (y + 2)(y + 6) = y² + 8y + 12

4. Binomios conjugados

Regla: son dos binomios iguales, uno con suma y otro con resta. Su resultado es la diferencia de cuadrados.

Ejemplo: (3m + 4)(3m - 4)

Paso 1: (3m)² = 9m²

Paso 2: 4² = 16

Paso 3: 9m² - 16

Resultado: (3m + 4)(3m - 4) = 9m² - 16

Factorización I

La factorización consiste en expresar una suma o resta algebraica como una multiplicación de factores. Es el proceso inverso de desarrollar ciertos productos notables.

1. Factor común

¿Cómo reconocerlo?

Cuando todos los términos tienen un número, una variable o ambos en común.

Procedimiento:

Busco el factor que se repite en todos los términos, lo coloco fuera del paréntesis y divido cada término entre ese factor.

Ejemplo resuelto:

12x³ + 18x² = 6x²(2x + 3)

El factor común es 6x².

Comprobación multiplicando de regreso:

6x²(2x + 3)

= 6x² · 2x + 6x² · 3

= 12x³ + 18x²

2. Trinomio cuadrado perfecto

¿Cómo reconocerlo?

Tiene tres términos. El primero y el último son cuadrados perfectos, y el término de en medio es el doble producto de sus raíces cuadradas.

Procedimiento:

Calculo las raíces cuadradas del primer y tercer término. Compruebo que el término de en medio sea el doble de su producto y escribo el binomio elevado al cuadrado.

Ejemplo resuelto:

x² + 14x + 49 = (x + 7)²

Las raíces cuadradas de x² y 49 son x y 7. El doble producto es 2(x)(7) = 14x.

Comprobación multiplicando de regreso:

(x + 7)² = (x + 7)(x + 7)

= x² + 7x + 7x + 49

= x² + 14x + 49

3. Diferencia de cuadrados

¿Cómo reconocerla?

Tiene dos términos separados por una resta y ambos son cuadrados perfectos.

Procedimiento:

Calculo la raíz cuadrada de cada término y formo dos binomios: uno con resta y otro con suma.

Ejemplo resuelto:

25x² - 36 = (5x - 6)(5x + 6)

Las raíces cuadradas son 5x y 6.

Comprobación multiplicando de regreso:

(5x - 6)(5x + 6)

= 25x² + 30x - 30x - 36

= 25x² - 36

Los términos del medio se cancelan.

4. Ida y regreso

La factorización es el proceso inverso de algunos productos notables. Al desarrollar los factores, regresamos a la expresión original.

Caso de factorización Ida: desarrollar Regreso: factorizar
Factor común a(b + c) = ab + ac ab + ac = a(b + c)
Trinomio cuadrado perfecto (a + b)² = a² + 2ab + b² a² + 2ab + b² = (a + b)²
Diferencia de cuadrados (a - b)(a + b) = a² - b² a² - b² = (a - b)(a + b)
Conclusión:

La factorización facilita la simplificación de expresiones algebraicas. Para resolverla correctamente, debo reconocer el caso, aplicar su regla y comprobar el resultado multiplicando los factores de regreso.

Pasos para resolver un problema
  1. Comprender el problema.
  2. Identificar el caso de factorización.
  3. Seleccionar la regla correcta.
  4. Realizar las operaciones.
  5. Comprobar multiplicando de regreso.
